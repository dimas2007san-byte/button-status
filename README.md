# Button Status

Простой веб-сервис на Python для проверки статуса кнопки (включена/выключена) в реальном времени.

## Описание

Сервис предоставляет возможность управления статусом (ON/OFF) через веб-интерфейс. Все подключенные клиенты автоматически получают обновления статуса через WebSocket.

## Эндпоинты

| URL | Описание |
|-----|----------|
| / | Главная страница с визуальным отображением статуса |

## Установка и запуск

### Способ 1: Локальный запуск

1) git clone https://github.com/dimas2007san-byte/button-status.git
2) cd button-status
3) pip install -r requirements.txt
4) python app.py

Сервер запустится на http://localhost:5000

## Использование

### Управление статусом

Нажми кнопку Переключить на главной странице. Статус изменится мгновенно во всех открытых вкладках.

### Веб-интерфейс

Открой в браузере http://localhost:5000/
